# 前端

React 19 / TypeScript / Vite。已实现 GEER 响应式登录、学员注册、邮箱验证、待验证和登录后约课界面。学员进入课程、日期、时间与雪场选择及“我的预约”，教练进入雪场管理、课程发布、批量排班和申请处理的工作区。身份页面使用已批准蓝色概念稿的雪道、锐角 GEER 字标与刻滑线；原始照片保留在 `ai-docs/design/` 作为素材来源。

```sh
npm ci
npm run dev
npm test
npm run typecheck
npm run build
npm run lint
```

开发服务器在 `http://localhost:5173`，将同源 `/api` 转发至本机 8080。先按[后端说明](../backend/README.md)用 IDEA 或 Docker 启动后端。邮件沙箱在 `http://localhost:8025`；注册后从收件箱打开验证链接。页面只在内存中保存当前身份，刷新时调用 `/api/auth/me` 恢复有效会话。

身份页面在约 360、390、768、1440、1672 像素宽度下经 Chrome 检查；桌面及手机截图见[实施计划 0002](../ai-docs/implement-plan/0002-student-identity.md)。注册密码长度按 Unicode 码点校验为 8–128。若更换 GEER 图片，请确认容器中的文件可由 NGINX 读取，并运行 `python3 deploy/smoke.py` 检查资源可访问。

约课页的操作与当前 API 见[0006 功能文档](../ai-docs/features/0006-post-login-booking-home.md)。首次使用需由教练设置雪场，发布课程和未来可用时间，学员才会看到可申请项。教练端有「创建课程」「管理可用时间」「预约申请」三个入口；雪场管理收在紧凑区域。在月历上点选多个未来日期，再统一设置当地起止时间和可选的当天限定雪场。页面预览完整两小时块与尾段；发布时整天替换选中日期原有的未确认时段。只要任一选中日有待确认申请，整批不覆盖；已确认预约保留。发布后在操作区和月历标出结果。课程可编辑或从学员选课列表移除，已有预约保持原状。教练拒绝申请时必须填写理由。学员提交申请后立即看到编号和待确认状态，可在预约卡片取消；已确认预约须距开课至少 24 小时才能取消。第一笔确认后当天锁定所选雪场，最后一节已确认预约取消后解锁。日期、时段、可选雪场和申请状态以服务端数据为准；待确认不锁定名额，价格为 CAD 且线下支付。390px/1440px 视觉检查记录见[实施计划 0006](../ai-docs/implement-plan/0006-post-login-booking-home.md)。

申请按钮旁会在提交前说明取消规则。邮件链接采用 `/#/my-bookings/{id}` 或 `/#/coach-applications/{id}`；未登录先登录，之后读取并突出显示指定预约的最新状态。其他账号不能通过链接读取该预约。详见[0007 功能文档](../ai-docs/features/0007-booking-email-notifications.md)。

## 关于 GEER

`/about-geer` 是无需登录的独立公开页，登录页与学员导航均有入口。教练工作区的“个人主页”支持资料、五种素材、上传/校验进度、保存草稿、预览及发布。视频点击前仅加载封面；证书和微信支持可键盘操作的弹层，复制失败可选择文本。编辑状态仅属于当前账号，离开/登出后清理。

本地上传还需要 IDEA 后端、9090 的 S3Mock 和 ffprobe，见[后端说明](../backend/README.md)。首次尚未发布时会显示准备中，不自动填入示例证书或账号。响应式和后台验收截图以 0008 计划中的实际证据为准。
