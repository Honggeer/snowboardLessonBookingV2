## 1. 目标、触发与范围

- 用户希望展示个人 profile、CASI 证书、小红书、抖音、微信和一个滑行高光视频；明确“无需登录也能看，方便分享给潜在学员”“就一个就够，我会专门制作一个视频，后台可自行编辑吧”。
- 公开 `/about-geer`，学员导航和登录页提供入口；登录页右上角显示一行「关于 GEER ↗」，字体 16px、字重 600、斜体，有链接下划线、可点击且键盘可聚焦；独立于预约数据加载，可直达/刷新/分享。访客可进入现有登录/注册和约课流程。
- 教练工作区增加“个人主页”，编辑、上传、保存草稿、预览、发布；公开只显示已发布版本。一个教练、一个当前视频，其他内容和素材都可自行替换。
- 本 revision 包含本地完整能力实现和测试、生产存储/分发适配器；不包含 AWS 资源创建、生产部署、在线转码、视频列表、社交动态抓取、自动资质核验或学员私有教学媒体。

## 3. 业务规则与未决事项

### 已确认视觉

用户 2026-10-02 明确“不错，完全按照这个模版生成”，以[桌面稿](../design/0008-about-geer-desktop-concept.png)和[手机稿](../design/0008-about-geer-mobile-concept.png)作为实现基准。[内置 imagegen 提示词](../design/0008-about-geer-prompts.md)留存；沿用已有滑行照片示意，证书/等级/账号占位不构成真实声明。

固定顺序：人物首屏 → 一个高光视频 → profile/教学方式与 CASI 证书 → 三种联系方式 → 蓝色约课区。首屏保留 GEER、照片、短介绍、预约/联系按钮；桌面简介与证书并排，手机纵向排列。沿用 GEER 蓝白、冰蓝底色和深蓝文本；实际 DOM/CSS 还原图片中的视觉关系。

### 可编辑字段和发布约束

| 字段/素材 | 上限或规则 | 发布条件 |
|---|---|---|
| 称呼、短介绍 | 40 / 160 个 Unicode 字符 | 必填；初始称呼可为 GEER |
| profile、教学理念 | 3000 / 1000 字符，纯文本 | 可选，空则隐藏对应内容 |
| 擅长方向、语言、服务区域 | 200 / 80 / 160 字符，纯文本 | 可选，不自动填履历 |
| 人物照片 | 一张 HERO，JPG/PNG | 必填 READY 素材 |

| 小红书/抖音 | 各账号 80 字符、主页 URL 2048 字符 | 可选；各平台账号/链接成对；仅 HTTPS 官方域名 |

每张图片最大 **8 MiB**、宽高各 ≤4096，仅真实 JPG/PNG；视频最大 **100 MiB**、时长 **120 秒**，实际 MP4、H.264/yuv420p、至多一个 AAC 音轨，长边 ≤1920、短边 ≤1080、≤60 fps，不允许其他流。建议用户制作 30–60 秒成片和专用封面；允许横竖屏，首版无转码。

草稿允许暂缺文字或成对字段，预览明确标注未完成；输入长度/链接/已引用媒体仍须合法。发布时执行全部完整性检查。未配置可选块隐藏，首次未发布返回明确空状态。真实资料未提供时，不把设计图占位/测试素材默认发布。证书可放大，不声明已向 CASI 核验。

## 4. 模块、端口与依赖

- `coachprofile` 拥有个人展示、草稿/公开快照和发布幂等记录；`media` 拥有上传、用途、对象、验证任务、引用/配额，不扩展登录账号承载这些内容。
- 单向 `coachprofile → media.application.port.in`，通过自己的出站端口及 module adapter 隔离；没有跨表 SQL 或反向依赖。
- 存储、真实内容探测、时钟/ID、持久化通过小端口隔离，domain/port 纯 Java。AWS SDK、ffprobe、ImageIO 位于出站 adapter；Web/定时入口只调用用例。
- 新模块加入架构检查，新增例外预期 0。沿用 ADR 0001，适用 WORK/ARCH/DEP、SEC/API/FE、MEDIA/ASYNC/OPS 约束，完整技术协议见计划第 4 节。

## 5. API 与前端契约

成功响应及错误体沿用 v2 既有约定；以下接口输出单独 Web DTO，不返回持久化 record、密钥或供应商错误。

| Method / Path | 权限 | 输入 | 成功输出 | HTTP/业务错误与幂等 |
|---|---|---|---|---|
| GET `/api/coach-profile` | 匿名可读 | 无 | 200：published 状态、公开字段、短时媒体 URL/过期时间；未发布时 published=false | 503 可重试；只签当前已发布引用 |
| GET `/api/coach/profile/draft` | COACH | 无 | 200：草稿/版本、已发布版本、预览媒体 URL | 401/403/503 |
| PUT `/api/coach/profile/draft` | COACH + CSRF | expectedVersion、字段/媒体 ID | 200：新草稿/版本 | 400 校验、401/403、409 旧版本或媒体未 READY |
| POST `/api/coach/profile/publish` | COACH + CSRF | draftVersion、Idempotency-Key | 200：发布版本 | 400/401/403/409；同键同请求重放，同键不同请求冲突 |
| POST `/api/coach/media/uploads` | COACH + CSRF | 用途、类型、大小、Idempotency-Key | 201：ID、PUT URL/必要 headers/到期时间 | 400/401/403/409 配额或活动上传、413 大小、429 频率、503；按用户/键去重 |
| POST `/api/coach/media/uploads/{id}/complete` | 上传归属 COACH + CSRF | ID | 202 验证中；200 已终结状态 | 400/401/403/404/409/413/503；按 ID 幂等，不重复发布 |
| GET `/api/coach/media/uploads/{id}` | 上传归属 COACH | ID | 200：状态/用途/探测元数据、READY 预览 URL 或安全错误码 | 401/403/404/503；前端有界轮询，终结停止 |

- 只有公开 GET 精确放行；ActorResolver/session 提供可信身份，业务用例再次验证角色/归属，所有写入维持 CSRF。前端 role/owner 不是授权证据。
- 每个展示组件有加载、未发布/空内容、失败和重试；联系和约课不被视频失败阻塞。证书/二维码弹层可键盘关闭、管理焦点；复制失败可手工选择文本。
- 教练保存失败保留输入，发布/上传按钮防重复。轮询每 2 秒、单次界面等待最多 2 分钟，仍处理中展示状态和手动刷新；不阻塞后台任务恢复。登出清空私人缓存。
- `/about-geer` 经 Vite/NGINX 直达/刷新可用；公开组件与预约数据加载分开。约课续接及邮件 hash 导航保留，不能因进入公开页清除有效登录态。

## 6. 数据、事务与并发

- V9 新增 profile/media 自有表，表名、归属和记录字段见计划第 4.2 节；不修改旧迁移，不保存媒体二进制或会过期的 URL。
- READ COMMITTED 下按“页面 → 按 ID 排序的媒体行”锁序保存/发布，通过 media 入站用例在同一 MySQL 事务更新引用。发布替换完整快照而非逐字段公开；锁内无对象存储/探测 IO。
- 上传申请以 actor+key+指纹去重；完成接口 CAS 固定 source versionId 并同事务写任务；发布按 actor+key 去重。相同键不同请求 409；草稿旧版本 409，不静默覆盖。
- staging 桶启用 versioning，缺失/null versionId 失败关闭。所有重试只复制固定版本至浏览器不可写的 frozen key，再校验冻结内容；暂存覆盖不能改变公开内容。
- 清理先锁 media 并检查引用/任务后标记 DELETING，保存/发布/完成均拒绝此状态；数据库 fencing 限制过期 worker 写回，迟到对象依靠后续回扫清理。

## 7. 异步任务与外部依赖

- AWS SDK 2.55.10；本地 S3Mock 5.2.3（9090、两个桶、假凭据）；ffprobe 9.0.2。精确接入、官方依据及本地/生产区别见计划第 4.5 节；依赖、探测工具和本地链路已实际验证。
- 一次 1 项的专用持久 worker，5 分钟租约/claimToken，单任务外部操作总超时 3 分钟；初次执行加最多 3 次重试（1/5/15 分钟），无效媒体直接拒绝。HTTP 请求只发起/查询，不同步完成重型校验。
- PUT 有效 10 分钟；最多 1 个未终结上传、每小时 20 个新申请、逻辑配额 1 GiB。签名可重用且不能硬限制实际云写入量；真实大小/类型上传后检查。
- 未完成上传 24 小时过期；终结的 staging 在授权到期满 24 小时清理所有版本/delete markers；未引用 READY 保留 7 天，拒绝/失败对象保留 24 小时。引用保护、分页、有界删除重试及 tombstone 回扫按计划第 4.4 节；迟到 PUT/复制仍须回收。
- 生产 S3 私有 + CloudFront OAC，frozen 还必须 viewer 签名。公开 API 只给已发布引用 15 分钟签名 URL，教练预览只给其可查看引用；staging 不经 CDN。公开响应 no-store，替换后旧签名到期前仍可用。
- S3Mock 不验证真实签名/到期，不能证明 IAM/OAC/CORS 有效。前后端本地链路与真实 AWS 部署验收分别记录。
