## 1. 目标、触发与范围

用户提出“只针对选课页面”：左上角 Logo 与登录页一致，教练添加课程时可上传图片，鼠标悬停课程卡片时显露图片，希望更酷。用户随后批准 revision 2 加入拖动构图，已完成本地验证。最新反馈要求图片仅显示在右半边，中间渐变、按固定宽度等比显示且只上下调整，并已确认“固定右半边 50%，图片按这部分宽度等比显示”。[实施计划 revision 3](../implement-plan/0009-course-selection-visuals.md)与[修订设计稿](../design/0009-right-half-review.html)已获用户“开始实现”批准；关联 [TODO-0018](../todo/0018-course-cover-right-half.md)。

包含学员选课视图的品牌标识与课程卡片、教练创建/编辑课程的封面字段及必要媒体接入。共用工作区页首使用同款标识；不重新设计其他工作区内容。课程、价格、日期/时间/雪场选择与预约确认沿用 [0006](0006-post-login-booking-home.md)，媒体能力沿用 [0008](0008-about-geer.md)。不包含视频封面卡、轮播图库、破坏原图的裁剪/缩放编辑器、预约规则变更或生产部署。

原 revision 2 视觉参考（保留历史）：[选课页与卡片状态概念图](../design/0009-course-selection-concept.png)，[提示词及局限](../design/0009-course-selection-prompts.md)。图中课程、金额和等级标签为示意，不自动创建课程或新增课程等级字段；主要评审 Logo、卡片和交互。默认隐藏图片以图底部状态演示及本规范为准，标题大横幅不纳入本次重做范围。

## 3. 业务规则与未决事项

以下为 revision 3 的可审阅规则；右侧 50% 宽度已有用户明确答复，整体修订已获用户“开始实现”批准。revision 2 的批准和验证记录继续保留。

- **品牌**：整理登录页现有字标为独立透明资源，桌面约 120–132px 宽、手机约 96–108px 宽；沿用黑色锐角字形和蓝色 G 内部细节。页首尺寸小，建议只保留 GEER 主字标。登录页整张品牌图不随此改版重做。
- **默认卡片**：延续纵向横卡，左半边白底深色文字，名称/介绍/两小时一对一/价格集中在左侧；右半边在未展示照片时同为纯白底。左右固定各 50%，文字可换行，窄屏价格移至文字下方，长标题不跨入照片区。
- **悬停/键盘焦点**：照片仅在右侧 50% 内沿柔和斜向渐变边缘显露/收起，约 280–360ms；照片左沿沿 20° 斜向边界从白色过渡到透明，与左侧衔接；动画与最终展示移动同一柔和边缘，无硬裁切线。卡片抬升至多 3px，左侧底色和文字颜色保持，照片不作悬停放大；悬停不改变卡片尺寸。
- **选择**：点击仍只选择课程，不提交预约；选中后图片保持展开，蓝边与勾选提示独立表达已选。焦点/悬停与已选择状态有明确区分，鼠标离开未选卡后恢复默认。
- **手机/触屏**：同样采用左右各半布局，无 hover 时直接显示右侧封面，一次点击选课；手机预览同步新布局，键盘 Enter/Space 可选择。`prefers-reduced-motion` 下直接切换。
- **课程封面**：一门课一张可选 JPG/PNG，沿用 8 MiB、宽高各 ≤4096；图片显示宽度为右侧区域宽度，高度按原始比例计算，不自动放大填满高度或横向裁切。过高图片仅裁切上下；过矮图片由浅色底承接，可上下对齐。保留原图，不生成新文件。桌面/手机共用垂直位置 0–100%，默认 50；拖动只调整上下位置，提供垂直滑杆和重置居中。现有 X 字段继续保存和兼容 API，但展示不应用 X，不再提供水平控件。
- **编辑**：选择图片→上传/验证→预览→保存课程。显示进度、失败原因、替换和移除入口。上传不等于保存课程；封面未 READY 时不能提交带该封面的课程。没有封面也可发布。
- **失败/空图**：无封面、未展开照片及图片失败时使用纯白底；加载失败保持文字可选，不能显示破图或隐藏价格。短时 URL 过期可重取一次，持续失败降级，不能无限重试。

| 起始状态 | 用例/操作者 | 前置条件 | 目标状态 | 失败与副作用 |
|---|---|---|---|---|

## 4. 模块、端口与依赖

`catalog` 拥有课程及封面资产 ID；`media` 拥有文件、生命周期和引用。依赖为 `catalog → 自身 CourseMedia 出站端口 → module adapter → media.application.port.in`；`media` 不读课程表。主页 `GEER` 与各 `COURSE:<courseId>` 的引用隔离，避免课程替换覆盖主页媒体。

应用端口仅使用纯 Java 类型；课程列表 Web DTO 增加可空封面信息，预约内部取课/锁课不进行媒体签名或外部 IO。沿用 [ADR 0001](../decisions/0001-v2-baseline.md) 与 ARCH/DEP、SEC/API/FE、MEDIA 规则，预期新增架构例外 0。

## 6. 数据、事务与并发

追加 V10，为 `catalog_course` 增加可空 `cover_asset_id` 及默认 50 的 `cover_position_x/y DECIMAL(5,2)`（CHECK 0–100）；`media_reference.consumer` 扩至 64 字符以容纳 `COURSE:<UUID>`，现有 GEER 行保留。旧迁移 append-only，旧课程不补假图，预约快照不新增图片依赖。

课程写入使用 READ COMMITTED，先锁定课程，再按稳定资产 ID 顺序锁定相关媒体；元数据和该课程媒体引用在同一事务内提交，失败一起回滚。清理仅在 media 内检查引用，不回读课程表。持有业务锁时不执行上传、下载或 URL 获取；只读展示链接由查询流程产生。完整兼容/锁序和验证见配对计划。

## 7. 异步任务与外部依赖

复用 0008 的私有存储、版本冻结、图片真实内容检查、持久任务、重试、fencing、引用保护及宽限清理，增加用途 COURSE_COVER。沿用教练总 1 GiB、每小时 20 次新上传、单活动任务和 10 分钟上传授权；与主页共享限额。保存失败或放弃的文件按现有孤立媒体期限回收。无需新的后台执行器或云资源。
