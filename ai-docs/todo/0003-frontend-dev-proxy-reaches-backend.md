- 相关功能/计划：[工程底座 0001](../features/0001-project-foundation.md)、[实施计划 0001](../implement-plan/0001-project-foundation.md)。

## 2. 背景

## 3. 问题与影响

开发者运行前端开发服务器时，页面会错误显示后端不可达，无法按文档进行本地联调。

## 4. 期望结果

按项目文档启动本地环境和前端开发服务器后，健康请求可以到达后端；访问范围仅限本机开发用途。

## 5. 完成判定

- 本机开发代理所使用的后端健康地址返回 UP。
- 原有同源容器入口仍能通过冒烟检查。
