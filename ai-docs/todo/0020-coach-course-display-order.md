# TODO-0020 — 教练课程列表先展示发布中的课程

## 1. 来源与关联

- 用户要求：“教练创建课程页面 已发布课程里，麻烦先列出来发布了的，下架的放在后面”。
- 关联 [功能 0006](../features/0006-post-login-booking-home.md)、[计划 0006 revision 4](../implement-plan/0006-post-login-booking-home.md)。

## 2. 背景

「创建课程」中的「已发布课程」按接口返回顺序展示，当前列表同时包含仍在发布和已下架的课程。

## 3. 问题与影响

已下架课程可能排在仍在发布的课程之前，使教练不容易先找到当前可管理的课程。加载更多或下架一门课程后也需要保持清楚的显示顺序。

## 4. 期望结果

教练当前列表先显示仍在发布的课程，再显示已下架课程；同组保持原顺序。加载更多和下架操作完成后仍按这个规则显示。

## 5. 完成判定

- 发布中和已下架课程混排时，发布中的所有已加载课程排在前面。
- 加载更多课程后，新增发布中课程仍排在已加载的下架课程之前。
- 下架课程成功后，该课程进入后面的下架组；标识和历史查看保留。
- 同组原有顺序保持，课程原数据不被显示排序修改。
