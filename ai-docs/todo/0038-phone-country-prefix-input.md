# TODO-0038 — 电话填写要求手输国家区号，增加学员操作负担

## 1. 来源与关联

- 用户先指出“我只在加拿大教课，只要输入号码就行了”，随后提议“分隔开，国家前缀让学员选，然后后面输入手机号”，并询问现成组件。
- 关联 [0011 功能](../features/0011-student-contact-phone.md)与[0011 revision 2 计划](../implement-plan/0011-student-contact-phone.md)。

## 2. 背景

已实现首次预约前电话必填、保存/预填及教练授权读取。当前表单和错误提示要求用户手输含 + 国家区号的完整号码，没有国家选择；加拿大本地号码因此被拒绝。

## 3. 问题与影响

学员习惯输入本地电话号码，额外手输国家区号容易漏写，导致无法保存或申请。用户希望把国家前缀与号码分开，让学员只填号码，默认适合加拿大教课场景。

## 4. 期望结果

默认加拿大，国家前缀可选择；号码输入独立且清楚。保存后的联系方式完整、准确，旧电话可继续预填和使用，教练仍可查看并联系。保留首次预约前必填和联系用途说明。

## 5. 完成判定

- 默认加拿大时输入本地号码即可保存/申请，不要求手输国家区号。
- 选择其他国家前缀后，完整号码和教练联系显示正确，不重复拼接前缀。
- 已存号码和粘贴的完整号码正确处理，不静默丢失或改写。
- 空值/格式错误反馈、读写失败/重试、账号作用域和既有预约流程仍正确。
- 手机及桌面国家选择、号码、用途和错误可见可操作，无横向溢出。
- 相关实现、验收与发布状态分开记录。
