# TODO-0014 — 首次访问时并行会话初始化使登录偶发失败

## 1. 来源与关联

- 发现于：0008 独立数据库 Chrome 联调，首次登录偶发返回拒绝响应，界面停留登录页；重新访问可成功。
- 相关：[0008 AC-07 与 P-04](../implement-plan/0008-about-geer.md)、[身份功能 0002](../features/0002-student-identity.md)。

## 2. 背景

匿名首次打开应用时，CSRF 与当前账号查询并发执行；两者依赖同一个浏览器 Session Cookie。快速提交登录还可能重复获取 CSRF。

## 3. 问题与影响

会话初始化存在响应顺序竞争，CSRF 与浏览器当前会话可能不匹配，影响访客从公开主页进入已有认证和约课流程。原有单元测试没有检查这项顺序。

## 4. 期望结果

首次访问和快速登录稳定使用同一初始化会话；公开展示仍能独立加载，已登录账号和邮件导航行为保持正确。

## 5. 完成判定

目标测试证明账号查询发生在会话建立之后，初始化期间不重复建立竞争会话；已有身份/邮件导航回归和真实浏览器登录、编辑与公开约课入口通过。
