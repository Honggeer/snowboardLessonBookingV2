# TODO-0019 — 课程照片边缘采用斜向渐变并去掉默认纹理

## 1. 来源与关联

- 用户反馈：“边缘渐变最好是斜着的 然后不展示的时候卡片的纹理就不要了”。
- 用户追加：“整体展开动画那个边界线我也想搞成模糊的，然后倾斜度和最后的边界一致，比现在边界倾斜度大一些”。
- 关联 [功能 0009](../features/0009-course-selection-visuals.md)、[计划 0009 revision 3](../implement-plan/0009-course-selection-visuals.md)。

## 2. 背景

右半边照片和上下构图已完成。当前照片左沿为竖直渐变，未展示照片时卡片右侧仍有几何纹理，用户要求进一步调整外观。

## 3. 问题与影响

竖直渐变和默认几何纹理不符合用户现在希望的简洁卡片外观，教练预览也需要反映相同的视觉效果。

## 4. 期望结果

照片左沿柔和地斜向过渡到白底；未展示照片、没有图片或图片加载失败时，卡片保持干净的纯白底。教练桌面和手机预览采用相同的照片边缘效果。

## 5. 完成判定

- 桌面和手机的照片边缘呈斜向渐变，左侧文字清晰；展开/最终/收起共用同一柔和斜边，倾斜度比初始展示更大。
- 未展开照片或无图时卡片无几何纹理。
- 图片区域仍为右侧一半，比例和纵向构图保持正常。
- 教练预览与选课卡片的边缘效果一致。
