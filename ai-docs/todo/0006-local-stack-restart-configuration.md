# TODO-0006 — 本地容器缺少可复用的启动配置

## 1. 来源与关联

- 发现于：0001 本地容器首次用临时命令环境变量启动后，直接运行文档中的 Compose 配置命令提示缺少必需变量。
- 相关功能/计划：[工程底座 0001](../features/0001-project-foundation.md)、[实施计划 0001](../implement-plan/0001-project-foundation.md)。

## 2. 背景

项目提供可复制的环境示例。当前验证环境中 MySQL 数据卷已经建立，重新启动需要沿用与该卷一致的本地数据库凭据。

## 3. 问题与影响

没有本地配置文件时，开发者无法直接按文档重启当前容器；若为已有数据库卷随意更换密码，后端也无法连接。

## 4. 期望结果

当前本地验证环境可直接使用文档中的 Compose 命令再次启动，并确保本地凭据不会进入 Git。

## 5. 完成判定

- 无需手动传入变量即可校验当前 Compose 配置。
- 同源入口仍健康，本地凭据文件被 Git 忽略。
