# TODO-0001 — 文档检查忽略生成的依赖文件

## 1. 来源与关联

- 发现于：0001 前端安装依赖后运行 `python3 ai-docs/check_docs.py`，报出 `frontend/node_modules/` 中第三方 README 的失效链接。
- 相关功能/计划：[工程底座 0001](../features/0001-project-foundation.md)、[实施计划 0001](../implement-plan/0001-project-foundation.md)。

## 2. 背景

项目文档检查原本在只有源码和 Markdown 的仓库中通过。前端安装依赖后，本地出现不纳入版本控制的第三方文档。

## 3. 问题与影响

检查把第三方生成文件当成项目文档，导致安装依赖的开发环境无法通过文档门禁，也淹没真正的项目链接错误。

## 4. 期望结果

文档门禁只检查项目维护的文档；本地安装依赖或构建后，结果仍与干净检出一致。

## 5. 完成判定

- 安装前端依赖后运行文档检查，项目文档仍被验证且检查通过。
- 项目文档中的真实失效链接仍被报告。
