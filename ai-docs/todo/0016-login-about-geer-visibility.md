# TODO-0016 — 登录页关于 GEER 入口不醒目且缺少可点击提示

## 1. 来源与关联

- 用户反馈：“关于GEER在登录页面也太小了吧……要让他们一眼看见，并且知道能点进去”。
- 相关：[0008 登录页展示入口与 P-04](../implement-plan/0008-about-geer.md)。

## 2. 背景

公开教练主页已经可无需登录访问。登录页入口位于页脚，继承 10px 小字样式；手机上还位于表单之后。

## 3. 问题与影响

2026-10-07 用户认为顶部位置不如放在「忘记密码」下方，并要求先 review 设计草图；当前顶部方案的技术完成不代表已满足最新视觉要求。

2026-10-06 修正前入口已位于右上角，为 16px/600/italic 的透明底蓝字；手机 top 4px，入口叠在品牌图上。用户再次反馈手机容易忽略，需要继续改善可见性。

潜在学员容易忽略教练展示入口，也难以立即判断它可以点击，降低公开主页的可发现性。

## 4. 期望结果

在登录页「欢迎回来」下方的原副标题位置展示「第一次访问？ 关于 GEER ↗」：前半句灰色，关于 GEER 是链接并带箭头，整行沿用原副标题字体；用户知道可点击、无需登录，桌面和手机都便于使用。

## 5. 完成判定

先提供用户要求的设计草图供 review；实际修改后，登录页只有一个关于 GEER 入口，位于用户确认的位置、可点击并支持键盘访问。手机页面无横向溢出且可正常滚动；进入现有公开主页并返回后，登录表单仍可正常使用。全页草图不作为各设备首屏可见的证据。
