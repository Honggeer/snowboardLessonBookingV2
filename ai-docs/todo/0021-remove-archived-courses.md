# TODO-0021 — 教练列表移除已下架课程并保留数据库记录

## 1. 来源与关联

- 用户原话：“已下架的直接删掉就好了，留着没意义”。
- 关联 [功能 0006](../features/0006-post-login-booking-home.md)、[计划 0006 revision 4](../implement-plan/0006-post-login-booking-home.md)、[TODO-0020](0020-coach-course-display-order.md)。

## 2. 背景

教练「已发布课程」目前保留已下架记录并放在列表后面。下架改变课程活动状态，保留历史课程行；已有预约通过外键关联课程并保存名称和价格快照。

## 3. 问题与影响

用户认为已下架课程继续占据课程列表没有意义，希望移除。提出时“删掉”尚未明确是移除列表展示还是永久删除数据；两种含义对现有预约关联、幂等记录与恢复的影响不同，不能混用。用户随后确认只从列表移除并保留数据库。

## 4. 期望结果

已下架课程从教练列表移除，不再占据当前课程管理列表；数据库记录和历史预约关联保留。

## 5. 完成判定

- 用户确认移除范围，并在关联功能/计划中记录该决定。
- 已下架课程不再出现在课程管理列表，初次加载、加载更多、下架成功和空列表均符合确认规则。
- 既有预约及历史课程数据保留，验证结果记录在关联计划中。

## 6. 未决事项与状态记录

- 2026-10-03：OPEN。已询问用户选择“只从列表移除，保留历史预约关联”或“永久删除课程记录”；依赖此答案的实现暂未开始。
- 2026-10-03：用户明确回复“从列表移除，数据库保留”；未决事项已解决。IN_PROGRESS，按关联 revision 4 的课程管理展示维护记录执行，只调整列表显示。
- 2026-10-03：DONE。初次加载和加载更多均隐藏已下架课程，下架成功后立即移除；最后一门课下架后显示空状态，全下架页有后续页时保留加载更多入口。目标 3/3 RED → GREEN、前端全量 51/51、类型/构建及 lint 通过；继续使用原下架接口，未引入数据库删除或改动历史预约，证据与限制见关联计划末尾。
