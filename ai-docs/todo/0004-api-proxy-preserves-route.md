# TODO-0004 — 同源 API 入口未保留演示接口路径

## 1. 来源与关联

- 发现于：0001 检查本地演示 API 时，经同源入口以有效本地认证访问已存在的演示接口路径，返回 404。
- 相关功能/计划：[工程底座 0001](../features/0001-project-foundation.md)、[实施计划 0001](../implement-plan/0001-project-foundation.md)。

## 2. 背景

后端切片测试已验证演示 API 路径，页面健康请求与同源入口也已通过。二者使用的入口路径不同，需要在联调时共同验证。

## 3. 问题与影响

入口对普通 API 路径的转发与后端路由不一致。后续若沿用相同方式，前端调用已实现接口仍会遇到 404。

## 4. 期望结果

同源入口能把演示 API 请求送达后端对应路径，同时健康检查继续正常返回。

## 5. 完成判定

- 有效本地认证请求经同源入口到达演示 API 路由。
- 页面和健康接口仍可通过同源入口访问。
- 前端开发服务器的代理行为与容器入口一致。
