# TODO-0022 — 本地高光视频接近一分钟时传输中断

## 1. 来源与关联

- 用户报告：“每次我播放个人展示页面的那个视频的时候，每到一分钟就会卡一下”，说明视频约一分三秒；补充“快满一分钟的时候，是5173”。
- 关联 [功能 0008](../features/0008-about-geer.md)、[计划 0008 revision 1](../implement-plan/0008-about-geer.md)的 AC-03 播放能力。

## 2. 背景

当前 IDEA 后端、Vite 5173 与 Docker S3Mock 5.2.3 为本地环境，公开视频地址指向 localhost:9090。已发布视频实际元数据为 65.292993 秒、89,123,600 字节、1920×1080、H.264/AAC；播放签名有效期约 15 分钟。

## 3. 问题与影响

本机 Chrome headless 实际打开 5173 页面并主动播放，进度在 60.220114 秒停住。网络随后出现 ERR_CONTENT_LENGTH_MISMATCH，S3Mock 同次请求约 30 秒后记录 AsyncRequestTimeoutException。约 32 秒停顿后浏览器重新请求尾段，并出现后续硬件解码错误；该次未正常播完。

快速完整下载可取得全部字节，首段和尾段 Range 均返回正确 206。将同一份视频完整下载后在同一 Chrome 本地文件播放，从 54 秒跨过一分钟直到结束，无再次 waiting/stalled、无解码错误或掉帧。证据指向本地 S3Mock 的异步传输超时与响应截断，具体修复尚未验证；不能据此宣称真实 AWS 播放已经验证。

## 4. 期望结果

本地公开主页的现有长视频能连续越过一分钟并正常播完，无响应截断、长时间停顿或其后的播放错误；图片、上传和既有媒体引用继续正常。

## 5. 完成判定

- 通过实际 5173 页面从头连续播放当前约 65 秒视频，正常到达 ended。
- 跨过一分钟时无本次观察到的 waiting/stalled 停顿、响应长度错误或解码错误。
- 相应本地媒体请求不再触发本次的异步超时日志。
- 修复及适用验证记录在关联计划，媒体文件、数据库引用和历史预约保留。
