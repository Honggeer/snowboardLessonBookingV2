# TODO-0008 — 已注册账号缺少安全的密码找回流程

## 1. 来源与关联

- 发现于：规划学员注册、邮箱验证与登录时，确认当前 0002 范围没有密码找回。
- 相关功能/计划：[身份功能 0002](../features/0002-student-identity.md)、[实施计划 0002](../implement-plan/0002-student-identity.md)。

## 2. 背景

学员与教练将使用邮箱、密码登录。忘记密码后，单靠登录/注册流程无法恢复账号访问。v1 有找回入口，但不自动成为 v2 功能，也不能复制其密钥或实现。

## 3. 问题与影响

如果没有安全的自助找回方式，忘记密码的用户只能联系教练或重新注册；人工传递密码会增加隐私与账号安全风险。

## 4. 期望结果

账号持有人可以通过已验证邮箱安全地重新设置密码；流程不泄漏邮箱是否已注册，且更改后旧凭据与既有会话按明确规则失效。

## 5. 完成判定

- 有独立获批计划和实际验证证据。
- 已验证邮箱的用户能完成找回；过期/重复/伪造请求不能改密码。
- 登录、现有会话与找回后的身份状态符合获批规则。

## 6. 未决事项与状态记录

- 需要用户澄清的问题：密码找回的优先级，以及教练账号是否使用相同流程。
- 2026-09-28：OPEN；记录后续需求，不在 0002 已提出的登录注册范围内，也不授权实现。
